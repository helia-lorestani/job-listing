A clean and responsive React application that allows users to filter job opportunities based on role, level, and technology tags. 


##  Tech Stack
- **Frontend:** React.js
- **State Management:** Redux Toolkit 


##  Features
- **Dynamic Filtering:** Filter job listings by clicking on tags (Frontend, Senior, JavaScript, etc.).
- **Multi-Category Selection:** Add multiple filters simultaneously to narrow down the search.
- **Global State Management:** Powered by **Redux Toolkit** for efficient and centralized data handling.
- **Responsive Design:** Optimized for a seamless experience on mobile , tablet and desktop.
